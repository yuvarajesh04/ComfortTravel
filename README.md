In this project based on travelling.
HOW TO RUN THIS PROJECT:-
1. Clone
   -> https://github.com/yuvarajesh04/ComfortTravel.git
   -> open your terminal type git clone above link
2. Enter into dir
   -> cd ComfortTravel
3. Setup Backend
   -> create env file named .env
   -> add variable PORT=5000
   -> add variable JWT_SECRET= you can write here what ever
   -> cd server
   -> npm install
   -> npm run dev -> Server will start after this command
4. Setup Frontend
   -> cd client
   -> npm run dev
